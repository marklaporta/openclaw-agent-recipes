# Contributing

Thanks for improving these agent recipes.

## How To Contribute

1. Fork the repository.
2. Create a branch in your fork.
3. Make the smallest useful change.
4. Open a pull request against `main`.

## What Good Contributions Look Like

- Public-safe: no private names, addresses, account IDs, tokens, chat IDs, medical details, medication names, dosing cadence, child ages/milestones, or family-specific facts.
- Reusable: prompts should tell a new user what prerequisites they need and how to wire them up.
- Practical: prefer concrete setup steps over abstract advice.
- Clear about prerequisites: if a capability requires email, calendar, health data, messaging, local scripts, or a wiki, say so.
- Concrete public examples are fine: public products, platforms, and local resources such as Oura Ring, Apple Health, Garmin, Google Calendar, and 510families.com are not private leaks by themselves.
- Wiki-aware: if a recipe mentions a wiki, reference Karpathy's LLM Wiki gist and name the supporting platform capability, such as OpenClaw `wiki_*` tools or a Hermes/local markdown vault with filesystem access.

## Maintainer Review

All changes should go through pull requests. The maintainer reviews and merges accepted changes.
